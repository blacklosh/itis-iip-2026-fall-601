# 1 занятие
## Как установить java ?

### Мы договорились использовать именно 21 джаву.

1. Скачать JDK 21 с официального сайта (oracle.com)
2. Установить, запомнить путь, куда установилось
Если у Вас windows:
3. Настроить переменные окружения:
3.1. Открыть проводник
3.2. ПКМ по "этот компьютер"
3.3. Свойства
3.4. Дополнительные параметры системы
3.5. Переменные среды
3.6. В нижнем окне находим строку с названием Path, нажимаем "изменить"
3.7. Создать -> в появившуюся строку внести путь до установленной джавы (до директории bin)
3.8. Перезапустить терминал

## Как понять, что джава установилась нормально?

В консоли набрать:
```
java --version
```
- если в ответ выводится версия джавы, то Вы сможете ЗАПУСКАТЬ чужие программы

В консоли набрать:
```
javac --version
```
- если в ответ выводится версия джавы, то Вы сможете СОЗДАВАТЬ свои собственные программы

## Как отправить домашку?

1. Сделать домашку (по сути, вы можете делать её в любой папке, не обязательно в репозитории) - результат работы это пары .java и .class файлов
2. В репозитории создать директорию homework-2026-MM-DD
3. В этой директории разместить результат работы - только .java файл
4. git add homework-2026-MM-DD/filename.java
5. git commit -m "осознанное описание коммита"
6. git push
7. Проверить в браузере, что в вашем репозитории отображается эта домашка (только .java файл)!
